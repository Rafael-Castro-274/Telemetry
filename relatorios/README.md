# Pasta de Relatórios

Esta pasta é destinada para armazenar os relatórios em PDF gerados após cada sessão.

## Estrutura

- `telemetry_YYYYMMDD_HHMMSS.pdf` - Relatório completo com gráficos da sessão

Os relatórios incluem análises detalhadas de:
- RPM
- Marcha
- Ângulo do Volante
- Acelerador
- Freio
- Velocidade
